# 站点 README 语法速查

> 这份文件本身就是用这套语法写的 —— 你把它临时挂到某条游戏上（`works.js` 里
> 把 `readme` 改成 `'data/readmes/_syntax.md'`）就能看到渲染后的样子。
> 渲染器是 `js/markdown.js`：零依赖、纯函数，规则以它为准。

[TOC]

## 怎么用

1. 写一个 `.md`，放 `data/readmes/` 下（名字随意，建议用游戏 id，例如 `semarlog.md`）。
2. `data/works.js` 里那条游戏加一行：

```js
readme: 'data/readmes/semarlog.md',
```

3. 选那张卡带 → 游乐区那块"说明书"就变成一页可滚动的 README。
   不写 / 取不到 → 退回 `detail` 数组，页面永远不会空。

## 标题与目录

`#` 到 `######`，**最多六级**；`#` 后面必须有空格（`#话题` 不是标题）。

单独一行写 `[TOC]` 或 `[[toc]]` → 自动生成目录（按标题层级嵌套）。

| 写法 | 效果 |
|:--|:--|
| `# 一级` | 一级标题（带下边框） |
| `## 二级` | 二级标题 |
| `### 三级` | 三级标题（字号最小的一档） |

标题会自动生成锚点 id：中文保留、空格转 `-`、标点去掉；
同名标题自动变成 `-1`、`-2`。所以 `[跳过去](#玩法)` 这种链接是能用的。

## 段落与换行

连续几行算**一个段落**。想在段落里强制换行，在行尾**打两个空格**：

这一行结尾有两个空格  
所以这一行从新的一行开始。

单独一行 `---` 是分隔线：

---

## 强调与代码

| 写法 | 效果 |
|:--|:--|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| 一对反引号包住 | `行内代码` |

- 想写**字面的星号**？用一对反引号包起来（`*这样*` 里的星号就不会被当成强调）。
  本渲染器**不支持**反斜杠转义（写 `\*` 不会变成字面的星号）。
- 行内代码优先级最高：`a*b*c` 里的星号不会变成斜体。

代码块用三个反引号（或三个波浪号），后面可以跟语言名 —— 只进 `data-lang`，**不做语法高亮**：

```csharp
// 例：站点与游戏的约定
Site.Msg("任务完成");
```

## 列表

- 无序：`-`、`*`、`+` 都行
- 缩进两格（或更多）就是嵌套：

  - 这是第二层
    - 这是第三层
      - 还能更深

- 任务列表（`- [x]` / `- [ ]`）：

- [x] 已经做完的
- [ ] 还没做的

1. 有序列表用 `1.` 或 `1)`
2. 同层从无序换成有序会自动分段

## 表格

**必须**有第二行那条分隔行，否则整块会被当成普通段落。

| 名字 | 数量 | 说明 |
|:--|--:|:-:|
| 左对齐 | 12 | 居中 |
| 写法是 `:--` | 写法是 `--:` | 写法是 `:-:` |

- 分隔行的单元格**只写一个 `-` 也认**（`:--` / `-` / `:-:` 都合法）。
- 单元格里的竖线用 `\|` 转义。
- 表格里**不能换行**；一行的单元格数量比表头多会被忽略多的。

## 链接与图片

| 写法 | 效果 |
|:--|:--|
| `[文字](https://example.com)` | [文字](https://example.com)（自动新窗口 + `rel=noopener`） |
| `[文字](assets/images/_test.jpg)` | 相对路径照原样，不开新窗口 |
| `[文字](#标题锚点)` | 跳到本页标题（面板自己滚，不会把整站滚走） |
| `![说明](assets/images/_test.jpg)` | 图片（自动限宽、懒加载） |

★ 只放行 `http` / `https` / `mailto` / 相对路径 / `#锚点`。
`javascript:`、`data:` 这类**整段原样显示**（不会变成链接，也不会被丢掉）：
[javascript:alert(1)](javascript:alert(1))

## 引用

> 一行开头的 `>` 就是引用块。
>
> 空行分段 —— 像现在这样就是两段。
> 引用块里**不解析**列表和表格（都按段落显示）。

## 不支持的写法

| 写法 | 实际会怎样 |
|:--|:--|
| 内联 HTML，例如 `<b>粗</b>` | 原样显示成字面文字（**不会执行**，这是有意的安全设计） |
| 反斜杠转义 `\*` | 不生效；要字面符号请用行内代码 |
| `===` / `---` 下划线式标题 | 不认；请统一用 `#` |
| 脚注、定义列表、自动链接 `<https://a.com>` | 不认 |
| 表格单元格内换行 / 引用块里嵌表格 | 不认 |

## 字体（改文案前必看）

- **标题和表格表头**走站里的展示字体 → 这些字**必须**在字体子集里。
  改了标题/表头文字，要跑一次：

```bash
node _dev/subset-font.js
```

  忘了跑也不会报错，只是那几个字会**静默**回退成系统字体；自检 `[2b]` 会拦下来。

- **正文**（段落、列表、表格内容、代码）走系统字体 → 随便写，不用管子集。

## 最小模板

```markdown
# 游戏名

一句话说清玩什么、你负责了哪部分。

## 操作

| 操作 | 按键 |
|:--|:--|
| 移动 | `W` `A` `S` `D` |

## 技术要点

- 引擎 / 版本 / 用到的框架
- 最难的一处、怎么解决的

## 待办

- [x] 已经做完的
- [ ] 还没做的
```
